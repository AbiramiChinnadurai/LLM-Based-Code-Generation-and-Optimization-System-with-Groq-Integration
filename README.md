# LLM-Based Code Generation and Optimization System

This project is a Streamlit-based app that integrates Groq API to:
- Generate machine learning code
- Act as an ML chatbot
- Optimize existing code

## Features
- Framework selection (PyTorch, TensorFlow, etc.)
- Code generation and download
- Chatbot for ML questions
- Code optimization suggestions

## Setup
```bash
pip install streamlit groq
streamlit run app.py
```
